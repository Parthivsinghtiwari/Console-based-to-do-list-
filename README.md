# Console-based-to-do-list-


A simple command-line to-do list app built with Python and SQLite. Users can add, view, complete, and delete tasks using a menu-driven interface.

---

## Features

- Add new tasks
- View tasks in a clean table format
- Mark tasks as done
- Delete tasks
- All tasks are stored in an SQLite database
